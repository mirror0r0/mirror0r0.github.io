{{- /* 音乐播放器数据与结构 - deta2/Music 下的 FLAC 与 LRC 在构建时扫描； - 歌词按文件名去掉全角括号内容后匹配，例如「歌名（mirrorAI）.flac」→「歌名.lrc」； - 只有音频、没有歌词时前端显示「暂无字幕」。 */ -}} {{- $musicDir := "deta2/Music" -}} {{- $entries := os.ReadDir $musicDir -}} {{- $lrcNames := slice -}} {{- range $entries -}} {{- if strings.HasSuffix (lower .Name) ".lrc" -}} {{- $lrcNames = $lrcNames | append .Name -}} {{- end -}} {{- end -}} {{- /* 个别文件名的字形差异在匹配时做一个别名修正。 */ -}} {{- $lrcAliases := dict "心做匕" "心做し" -}} {{- $tracks := slice -}} {{- range $entries -}} {{- if strings.HasSuffix (lower .Name) ".flac" -}} {{- $base := strings.TrimSuffix (path.Ext .Name) .Name -}} {{- $title := $base | replaceRE "（[^）]*）" "" | strings.TrimSpace -}} {{- if not $title -}}{{- $title = $base -}}{{- end -}} {{- $subtitle := "" -}} {{- with findRE "（[^）]*）" $base 1 -}} {{- $subtitle = index . 0 | strings.TrimPrefix "（" | strings.TrimSuffix "）" -}} {{- end -}} {{- $lrcName := printf "%s.lrc" $title -}} {{- if not (in $lrcNames $lrcName) -}} {{- with index $lrcAliases $title -}} {{- $aliasName := printf "%s.lrc" . -}} {{- if in $lrcNames $aliasName -}}{{- $lrcName = $aliasName -}}{{- end -}} {{- end -}} {{- end -}} {{- $lrcURL := "" -}} {{- if in $lrcNames $lrcName -}} {{- $lrcURL = printf "%s/%s" $musicDir $lrcName | relURL -}} {{- end -}} {{- $tracks = $tracks | append (dict "title" $title "name" $base "subtitle" $subtitle "src" (printf "%s/%s" $musicDir .Name | relURL) "lrc" $lrcURL ) -}} {{- end -}} {{- end -}} {{- $tracks = sort $tracks "title" "asc" -}}
